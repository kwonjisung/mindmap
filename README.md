# 생각가지

브라우저에서 바로 쓰는 마인드맵 앱입니다. 설치 없이 `index.html` 하나로 돌아갑니다.

## 기능

- **AI로 만들기** — 시작 화면에 주제나 내용을 적으면 AI가 마인드맵을 그려 줍니다. 1단계(심플)·2단계(보통)·3단계(심화)로 얼마나 자세히 만들지 고르고, 원하면 AI가 먼저 질문 3개를 던집니다. 답은 직접 고르거나 'AI가 대신 답하기'로 채울 수 있습니다.
- **시작 화면** — 맨 위에 마인드맵의 장점을 담은 한 줄이 열 때마다 바뀌어 나옵니다. 이어서 하기, 빈 페이지와 예시 5종(새 게임 기획, 주말 가족 여행, 이번 주 계획, 책 한 권 정리, 육하원칙 생각 정리), AI로 만들기, 내 맵 순서로 배치되어 있습니다.
- **자유로운 가지 뻗기** — 하위 가지(Tab), 같은 단계 가지(Enter) 추가. 끌어서 아무 데나 옮기고, 다른 가지 위에 놓으면 그 아래로 붙습니다.
- **키보드만으로 편집** — 방향키로 가지 사이를 옮겨 다니고, 추가·삭제·편집·순서 바꾸기까지 키보드로 합니다.
- **가지 접기·펼치기** — 가지마다 하위 가지를 접고 펼칩니다. 접힌 가지에는 숨은 가지 수가 표시되고, 누르면 펼쳐집니다. 메뉴에서 '모두 펼치기', '첫 단계만 보기'도 할 수 있습니다.
- **전체 단계 접기·펼치기** — 화면 왼쪽 아래(좁은 화면은 위쪽) '단계' 막대에서 맵 전체를 한 단계씩 접고 펼치거나, 1·2·3·전체 중 원하는 단계까지만 볼 수 있습니다. 심화 마인드맵을 훑어볼 때 좋습니다.
- **글꼴 선택** — 맵마다 글꼴 8종(깔끔한 고딕 기본, 나눔고딕, IBM 플렉스 산스, 고운 돋움, 도현, 주아, 나눔명조, 나눔손글씨 펜) 중 선택.
- **자동 정리** — 글을 쓰거나 가지를 추가·삭제·접으면 바로 정리됩니다. 메뉴에서 끌 수 있습니다.
- **가지 모양 5종** — 양쪽, 오른쪽, 왼쪽, 아래로(조직도형), 목록형(들여쓰기 트리).
- **색 테마 20종** — 다크(미드나잇, 네온 아케이드, 칠판 등), 깔끔(화이트, 흑백 인쇄용 등), 컬러풀(무지개, 캔디 등). 맵 내용에 어울리는 테마를 '추천'으로 앞에 보여 줍니다.
- **여러 주제** — 빈 곳을 더블클릭하면 새 주제(메인 가지)가 생깁니다. 주제끼리 겹치지 않게 자동으로 떨어뜨립니다.
- **끌어서 놓기** — 형제 사이에 놓으면 순서가 바뀌고, 다른 가지 가운데에 놓으면 그 아래로 들어갑니다.
- **이모지** — 6개 분류에서 고르거나 키보드 이모지를 직접 입력.
- **가지 색** — 9가지 색. 고른 색은 아래 가지에도 적용됩니다.
- **내보내기** — PNG(테마 배경/투명), PDF(A4·A3·맵 크기에 맞춤, 방향 자동), 제목 넣기 선택.
- **나눠서 출력** — PDF에서 주요 가지(섹션)를 2개 또는 3개씩 묶어 장마다 크게 출력합니다. 첫 장에 전체 지도를 넣을 수 있고, 각 장 제목에 섹션 이름과 쪽 번호가 붙습니다.
- **인쇄** — 내보내기 창의 '인쇄' 버튼.
- **자동 저장 · 내 맵** — 고칠 때마다 자동으로 저장되고 위쪽에 '저장됨'이 표시됩니다. 맵은 하나씩 따로 보관되어 시작 화면의 '내 맵'에서 미리보기와 함께 열고, 복제하고, 지울 수 있습니다. 새 맵을 시작해도 이전 맵은 사라지지 않습니다.
- **버전 기록** — 고치는 동안 10분마다 그 시점이 자동으로 남고(맵마다 최근 20개), 메뉴의 '버전 기록'에서 원하는 시점으로 되돌릴 수 있습니다. 되돌리기 전에 그 시점의 맵을 미리보기로 보고, 되돌리면 사라지는 가지·다시 생기는 가지·글자가 바뀌는 가지를 확인할 수 있습니다. '지금 시점 기록하기'로 직접 남길 수도 있습니다.
- **파일 보관** — 메뉴에서 `.json`으로 보관하고, 보관 파일을 열면 새 맵으로 들어옵니다. 저장은 브라우저(IndexedDB)에 되므로 브라우저 데이터를 지우기 전에는 파일로 보관해 두세요.
- **분석** — 위쪽 '분석' 버튼을 누르면 앱이 어떻게 돌아가는지 보여 줍니다. 지금 연 맵의 현황(가지 수·깊이·모양·테마·저장 시각), 전체 구조 다이어그램, AI 흐름 다이어그램, 핵심 원리 6가지가 들어 있습니다.
- 되돌리기/다시 실행, 확대·축소(Ctrl+휠, 두 손가락), 라이트/다크 테마.

## 단축키

Ctrl(⌘), Shift, Alt를 잠깐 누르고 있으면 그 키와 함께 쓸 수 있는 단축키가 반투명하게 떠오릅니다.

| 키 | 동작 |
| --- | --- |
| ← → | 부모 · 자식 가지로 이동 |
| ↑ ↓ | 위 · 아래 가지로 이동 |
| Alt + ↑ ↓ | 같은 단계 안에서 순서 바꾸기 ('아래로' 모양은 Alt + ← →) |
| Tab | 하위 가지 추가 |
| Enter | 같은 단계 가지 추가 |
| F2 / Space / 더블클릭 | 글자 고치기 (Enter로 완료) |
| 바로 타자 | 선택한 가지 글자를 새로 쓰기 |
| Delete | 가지 지우기 |
| Ctrl + + / − | 확대 / 축소 |
| Ctrl + 0 | 100% 크기 |
| Shift + 1 | 전체 보기 |
| 빈 곳 더블클릭 | 새 주제 만들기 |
| - / + | 하위 가지 접기 / 펼치기 |
| . | 접기 · 펼치기 전환 |
| Alt + − / + | 전체 맵 한 단계 접기 / 펼치기 |
| Alt + 1~9 | 그 단계까지만 보기 (Alt + 0: 전체) |
| ? | 단축키 보기 |
| Ctrl+Z / Ctrl+Shift+Z | 되돌리기 / 다시 실행 |
| Esc | 선택 해제 |

## AI 사용

- Claude 안(아티팩트)에서 열면 따로 설정 없이 내 Claude 계정으로 AI를 씁니다.
- `index.html`이나 GitHub Pages로 열면 시작 화면에 Claude API 키 칸이 나옵니다. 키는 그 브라우저에만 저장되고 Anthropic API(`claude-sonnet-5-5`)로만 보내집니다. 공용 컴퓨터에서는 쓴 뒤 '키 지우기'를 눌러 주세요.

## 실행

`index.html`을 브라우저로 열면 됩니다. GitHub Pages를 켜면(Settings → Pages → `main` 브랜치) 링크로도 쓸 수 있습니다.

PDF 생성에는 [jsPDF](https://github.com/parallax/jsPDF) 2.5.1(cdnjs), 글꼴은 Google Fonts(Noto Sans KR, Nanum Gothic, IBM Plex Sans KR, Gowun Dodum, Do Hyeon, Jua, Nanum Myeongjo, Nanum Pen Script)를 씁니다.
